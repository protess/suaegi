## 0. 헌장 질문 해결 — 배치로 푼다(옵션 c)
정찰 Q4의 세 선택지 중:
- (a) `suaegi-misc`에 `url` 추가 = **무의존 헌장 파기** → 기각.
- (b) WHATWG host 파싱 손코딩 = **credential-confusion 방어(`repo-icon.ts:51-52`)와 IDNA가 걸린 보안 경계** →
  에러 표면이 거대하고 위험 → 기각.
- **(c) 의존 허용 크레이트로 이관 → 채택.**

**`suaegi-forge`가 정답이다(리드 실측):**
① `url`을 **이미 의존**한다(hosted-review M4에서 추가). ② `suaegi-misc`도 이미 의존한다(hosted-review M3) →
`js_trim`/`is_js_whitespace` 사용 가능. ③ **응집도가 실재한다** — `github_identity.rs:24`의 `is_default_github_host`가
바로 그 **github.com-vs-GHES 호스트 경계**를 다루고, `normalizeGitHubAvatarHost`(`repo-icon.ts:44-62`)가 같은 축이다.
→ **`suaegi-misc` 헌장은 변경하지 않는다.**

## 1. 계약 결정

- **U1 — 배치는 `suaegi-forge`, 새 의존 0.** 위 근거. `lucide`/`emoji` 분기가 순수 UI라 misc스럽지만,
  **의존을 요구하는 부분(favicon URL, github avatar, image src 검증)이 전부 URL/host 관심사**이고 그중 둘은
  GitHub 전용이다. 134L짜리를 쪼개는 것은 과설계 → 모듈 통째로 forge에.
- **U2 (T13) — 3-state 반환을 **전용 enum**으로.** `sanitizeRepoIcon`은 `RepoIcon | null | undefined`를 낸다:
  **`undefined` = 거절/변경 없음**, **`null` = 명시적 리셋**. 오라클 `test:75-77`이 `null → null`을 못박는다.
  `Option<Option<RepoIcon>>`는 읽기 어렵다 → `pub enum SanitizedRepoIcon { Icon(RepoIcon), Reset, Rejected }`
  (`Reset` ← `null`, `Rejected` ← `undefined`). **절대 `Option<RepoIcon>` 하나로 뭉개지 말 것.**
- **U3 (T1/T2) — ⚠️ **한 파일 안에 케이스 폴딩 메커니즘이 둘** 있다. 반드시 구분한다([[js-lowercase-two-mechanisms]]).**
  - `:45` `rawHost?.trim().toLowerCase()` = **`String.prototype.toLowerCase()` = full Unicode** →
    Rust **`str::to_lowercase()`**. U+212A KELVIN → `k`로 접힌다.
  - `:66`, `:81` 정규식 **`/i` (non-`u`)** = ECMAScript Canonicalize = **비-ASCII를 ASCII로 접지 않음** →
    Rust **`eq_ignore_ascii_case`/ASCII 비교**. U+212A는 `k`로 **안** 접힌다.
  **양방향 핀 필수**: 호스트의 U+212A는 폴딩되고, data-URL/`.png` 매칭의 U+212A는 폴딩되지 **않는다**.
- **U4 (T4/T5) — trim 6곳은 `suaegi_misc::js_trim`, 단 `source`는 **trim 안 함**.**
  trim 사이트: `:16`(favicon 입력), `:45`(host), `:100`(lucide name), `:108`(emoji), `:116`(src), `:124`(label).
  **`:117` `source`는 의도적으로 trim 안 한다** → `' github '`는 **거절**. `str::trim` 금지(U+FEFF/U+0085 발산).
- **U5 (T6/T7) — 캡은 전부 **UTF-16 code unit**, 라벨 절단은 **snap-down**.**
  `:101` lucide name > 40(패턴이 ASCII 강제라 len==chars==bytes), `:109` emoji > 16(**`'🚀'`=2 unit**),
  `:118` src > 409600. 전부 `encode_utf16().count()`.
  `:124` `label.slice(0, 80)`: 80번째 unit이 서로게이트 페어를 가르면 JS는 **lone surrogate**를 만드는데 Rust `&str`은
  **표현 불가** → **snap-down(그 astral 글자를 통째로 버림, 결과 79 unit)**. 선례 `codex_auth_errors.rs:79
  utf16_slice_prefix`. **문서화된 divergence**로 명시 + 핀.
  ⚠ 순서: **trim → slice**이고 **자른 뒤 재trim 없음**(뒤에 공백이 남을 수 있다).
- **U6 (T20) — `.host`와 `.hostname`을 같은 파일에서 **다르게** 쓴다.**
  - `:53`, `:57` **`url.host`(포트 포함)** → `host_str()` + `port()` **재조립**. **`port_or_known_default()` 금지**
    (기본 포트를 붙여 WHATWG와 어긋난다). 선례: `hosted_review_gitlab.rs`의 K1.
  - `:26`, `:84` **`url.hostname`(포트 제외)** → `host_str()`만.
- **U7 (T21) — `encodeURIComponent`는 **정확한 unreserved 집합**으로 새로 쓴다.**
  비이스케이프 = `A-Za-z0-9 - _ . ! ~ * ' ( )`. ⚠ 기존 두 구현(`gitlab/parse.rs:355`, `github_http/forge.rs:241`)은
  RFC3986 unreserved(`-_.~`)라 **`!'()*`를 과다 이스케이프**한다 → **재사용 금지**(다른 크레이트라 접근도 불가).
- **U8 — `github_identity::is_default_github_host` **재사용 금지**.** 이름이 비슷하지만 **다른 함수**다:
  그건 **술어**(trim+lower 후 `=="github.com"`), 이건 **정규화기**(`|| 'github.com'` 후 `new URL` 6조건 검증 →
  호스트 문자열 반환). 재사용하면 검증이 통째로 사라진다.
- **U9 (T18) — `RepoIconImageSource`는 정확히 4변형**(`upload`/`file`/`favicon`/`github`), 미지 값 → **Rejected**(보수적).
- **U10 (T11) — 빈 label은 **키 자체가 없다**.** `:129` `label ? {label} : {}` → `Option<String>`의 `None`
  (`Some("")` 아님). 오라클 `test:40-50`이 favicon 케이스로 못박음.
- **U11 — 443 탈출구를 축자 보존.** `:51-58` 6조건 AND: `!username`, `!password`,
  **`url.host === candidate` 또는 `` `${url.host}:443` === candidate ``**, `pathname === '/'`, `!search`, `!hash`.
  세 번째의 **양방향 문자열 동등성**이 사실상 "정규화가 항등이어야 한다"는 요구다 → IDN 호스트는 punycode로 바뀌어
  불일치 → **`github.com` 폴백**. 오라클: `'ghe.example:443'` → 출력에서 포트가 **사라짐**(`test:123-125`),
  `'github.com@evil.example'` → **`github.com`으로 폴백**(`test:126-128`, credential confusion 방어).
- **U12 — `githubAvatarIcon`의 label은 sanitize-stable하지 않다.** `:40`은 `owner/repo`를 **무제한·미trim**으로 넣는데
  `:124`는 trim+80 절단을 한다 → 자기 출력이 sanitize를 통과하며 바뀔 수 있다. **상류 비일관성이지만 축자 보존**(주석).
- **U13 — favicon 분기의 구멍을 축자 보존.** `:84` `hostname === 'www.google.com' && pathname === '/s2/favicons'` —
  **포트 미검증**(`https://www.google.com:8443/s2/favicons` 통과), **쿼리 미검증**. 조이지 말 것(주석).
- **U14 — `faviconUrlFromWebsite`는 **오라클 커버리지 0**** → 핀을 직접 다 써야 한다.
  `:22` `trimmed.includes('://')`는 **위치 무관 부분문자열 검사이지 scheme 검사가 아니다** → `'a/b://c'`는
  그대로 파싱 시도 → 실패 → `null`. `'example.com'`은 `https://` 접두.
  `:23` protocol이 `http:`/`https:`가 아니거나 `!hostname`이면 `null`.

## 2. 마일스톤 (단일 PR)
`crates/suaegi-forge/src/repo_icon.rs` + `lib.rs` 선언/re-export. **의존 추가 없음.**
Export: `RepoIcon`(3-variant), `RepoIconImageSource`(4), `SanitizedRepoIcon`(3), `MAX_REPO_ICON_UPLOAD_BYTES`,
`MAX_REPO_ICON_DATA_URL_LENGTH`, `favicon_url_from_website`, `github_avatar_icon`, `sanitize_repo_icon`.
정규식 3개(`:11`, `:66`, `:81`)는 **손코딩**(전부 앵커 단순 패턴, lookaround/`/g` 없음; forge에 `regex`는 있으나
`\d` Unicode 함정과 하우스 손코딩 선례를 따른다).

**오라클(17케이스 전량):** lucide/emoji/image 수용 7(github 쿼리스트링·GHES 호스트·favicon **label 키 부재**·
data-URL `upload`/`file`); `null → Reset`; 거절 6(`javascript:`·409600 캡·svg mime·중첩 경로·credential);
`githubAvatarIcon` 3(포트 유지·**443 탈출구**·**credential confusion 폴백**).

**추가 핀(오라클 침묵 — 이 모듈은 커버리지가 얇다):** U14 `faviconUrlFromWebsite` **전부**(빈/공백만/`'://'` 오탐/
scheme 거절/`hostname` 인코딩); U3 **양방향 U+212A**; U4 `source` 미trim·U+FEFF trim; U5 emoji 16 경계
(`'🚀'`×8 통과 vs ×9 거절)·src 409600 경계·label 80 **서로게이트 straddle**; U6 `.host` vs `.hostname`;
U7 `!'()*` 미이스케이프; U9 미지 source → Rejected; U10 빈 label 키 부재; U11 IDN 폴백·`pathname!=='/'`·
`search`/`hash` 거부; `/.png` 거절(`[^/?#]+`가 1자 이상); `/i` 대문자 data-URL 통과.

*mutation:* U2 Reset/Rejected 통합, U3 두 메커니즘 뒤바꿈(양방향), U4 `js_trim`→`trim`·`source`에 trim 추가,
U5 utf16→chars/bytes·snap-down 제거, U6 `port_or_known_default`·`.hostname`↔`.host` 스왑, U7 RFC3986 집합,
U9 미지 source 허용, U10 빈 label을 `Some("")`으로, U11 443 탈출구 제거·6조건 중 하나 제거.
