## 0. Codex 정정 2건 (근거 정밀화)
- **F0a** — 비-`u` JS `/i`는 "전역 ASCII-only 폴딩"이 아니다. 정확한 규칙: **비-ASCII 문자를 ASCII로 폴딩하지 않는다**
  (`/k/i`는 U+212A KELVIN, `/s/i`는 U+017F long-s를 **불매치**). 10개 패턴이 **전부 ASCII**이므로 결론은 동일:
  **ASCII 소문자화 + 리터럴 `contains`가 정확히 등가**.
- **F0b** — `extractCodexAuthError`의 누적 프리픽스 fallback이 도달 불가인 이유는 "경계마다 리터럴 공백" 때문이 아니라
  **어떤 패턴도 `\n`을 소비할 수 없기 때문**. (이식하되 도달 불가로 문서화.)

## 1. 계약 결정

- **F1 — codex 패턴 10개를 리터럴 15개로 전개, regex 미사용.** 입력 줄을 **ASCII 소문자화**(`to_ascii_lowercase` —
  full Unicode 아님! F0a) 후 아래 15개 리터럴 `contains` OR. 전개 목록(Codex 검증 완료):
  `access token could not be refreshed` / `authentication session could not be refreshed` /
  `refresh token has expired` / `refresh token was already used` / `refresh token was revoked` /
  `you have since logged out or signed in to another account` / `please log out and sign in again` /
  `please sign in again` / `please reauthenticate` / `not logged in` / `token data is not available` /
  `auth is missing` / `auth tokens are missing` / `auth does not expose` / `chatgpt authentication required`.
  (`:5` `please (?:log out and )?sign in again`는 **2개**, `:4`는 3개, `:10`은 3개로 전개.)
- **F2 — ANSI 제거는 CSI만**(`:16` `/\x1b\[[0-9;]*[a-zA-Z]/g`). OSC(`ESC ]`)·맨 ESC·비-ASCII-letter CSI final은
  **남긴다**. 제거는 **매칭보다 먼저**, 줄 단위(`:33`), 그 다음 `js_trim`.
- **F3 — 4000 cap은 UTF-16 유닛 카운트 + char 경계 내림 스냅**(M1M2의 D1과 동일 정책, `suaegi-misc` 선례).
  `.slice(0,4000)` 2곳(`:38`,`:42`) + 누적 가드 `cleanPrefix.length < 4000`(`:40`)도 **UTF-16 길이**.
  오라클 미검증(서로게이트/경계 테스트 없음) → **핀 필수**.
- **F4 — 줄 분할기는 `<=` 계약으로 별도 함수**(M1M2의 `<` 함수와 **통합 금지**, Codex C). codex는
  `lineStart <= output.length`(`:65`) → `""`→`[""]`, `"a\n"`→`["a",""]`. field-scanner는 `<` → `[]`, `["a"]`.
  **두 계약을 각각 핀**(형제 발산이 실재).
- **F5 — harness 정규식은 수제 스캔으로 대체**(Codex D). `^<` → ASCII `a-z` 1자 → `a-z0-9-` 0자 이상 →
  다음 스칼라가 **`>` 또는 `is_js_whitespace(c)` 또는 문자열 끝**이면 매치. `\s`를 Rust regex로 쓰면
  **역방향 발산**(JS: U+FEFF 포함/U+0085 제외 ↔ Rust: 반대). `js_ws::is_js_whitespace` 재사용.
- **F6 — 파이프라인 순서: `js_trim` → **ASCII 소문자화** → 길이-0 가드 → 태그 스캔 → 프리픽스.**
  (`:55` `trim().toLowerCase()`가 먼저라 정규식에 `/i`가 없다 — 순서 뒤집으면 깨진다.)
  ⚠ 소문자화는 태그/프리픽스가 전부 ASCII이므로 `to_ascii_lowercase`로 충분하고, full `to_lowercase`는
  `İ`→2자 확장 등 불필요한 발산 위험. **ASCII 소문자화로 통일**(F1과 동일 판단).
- **F7 — 태그 19개 + 프리픽스 7개 정확 전사**(Codex verbatim 대조 완료).
  태그: `agent-message`,`bash-input`,`bash-stderr`,`bash-stdout`,`command-args`,`command-message`,`command-name`,
  `cross-session-message`,`fork-boilerplate`,`local-command-caveat`,`local-command-stderr`,`local-command-stdout`,
  `mcp-polling-update`,`mcp-resource-update`,`system-reminder`,`task-notification`,`teammate-message`,
  `user-memory-input`,`user-prompt-submit-hook`. **`channel`은 의도적 제외**(`:39-41` — bare `<channel>`은 실제 RSS/XML
  붙여넣기; 하네스는 속성 형태만 emit).
  프리픽스(**공백·마침표 유무가 load-bearing**): `<channel source=` / `[request interrupted`(닫는 `]` 없음) /
  `a message arrived from `(**후행 공백**) / `another claude session sent a message` /
  `no response requested.`(**마침표**) /
  `caveat: the messages below were generated by the user while running local commands`(**마침표 없음**) /
  `this session is being continued from a previous conversation`.
- **F8 — `extractCodexAuthError`는 매치 스팬이 아니라 정제된 줄 전체를 반환**(`:37-39`). fallback(`:46`)은
  이식하되 **도달 불가 주석**(F0b).
